# E-commerce SQL Project 🗄️

Учебный проект по проектированию базы данных для интернет-магазина. 
Включает в себя создание схемы (DDL), наполнение тестовыми данными (DML) и написание аналитических запросов (SQL).

## 🛠 Стек
- **SQL** (диалект: MySQL / PostgreSQL — уточни, что используешь).
- **DBeaver** или **pgAdmin** (для работы с базой).

## 📂 Структура проекта
- `schema.sql` — создание базы данных и всех таблиц (с внешними ключами и ограничениями).
- `sample_data.sql` — скрипт для наполнения таблиц тестовыми данными (клиенты, поставщики, товары, заказы).
- `queries.sql` — набор SQL-запросов для аналитики (например, выручка, топ товаров, активность клиентов).

## 🗄️ Схема базы данных (Таблицы)
1. **Customers** — клиенты (имя, email, город, баллы лояльности).
2. **Suppliers** — поставщики (компания, контактное лицо, телефон).
3. **Products** — товары (название, категория, цена, остаток на складе, привязка к поставщику).
4. **Orders** — заказы (клиент, дата, статус, общая сумма).
5. **Order_items** — позиции заказа (какой товар, сколько, цена за штуку).

*В схеме настроены связи `FOREIGN KEY`, каскадное удаление (`ON DELETE CASCADE`) и проверки (`CHECK` на положительную цену и остаток).*

## 🚀 Как запустить
1. Установи MySQL или PostgreSQL.
2. Создай базу данных (или выполни `CREATE DATABASE ecommerce_analysis;`).
3. Выполни скрипт `schema.sql` для создания таблиц.
4. Выполни скрипт `sample_data.sql` для наполнения данными.
5. Запускай запросы из `queries.sql` в твоем SQL-клиенте.
